# XATP

XATP 项目的公开介绍、发布说明与成果展示入口。

当前尚无正式公开版本。可用功能、安装方式和使用范围以今后的正式发布内容为准。

## 仓库用途

- `public-xatp`：默认分支，维护公开说明。
- `master`：保留 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的原始源码与历史，作为上游更新参考。

项目的内部开发、测试和运行资料在独立的私有仓库中维护。

## 上游项目

DeepSeek Harness 的源码、许可证与第三方声明见本仓库的 [master 分支](https://github.com/KRPCT/dsh-XATP/tree/master)。本页不表示上游项目已发布或认可 XATP 的功能。

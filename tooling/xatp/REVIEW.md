The new DSH headless test dispatches a real native tool through the installed agent loop. A local scripted model endpoint receives the two matching tool receipts, which are verified again from SQLite. The installed Web panel was used to edit a graph prompt, save the graph, rehearse the shot and read the saved prompt and receipts from the same project. The portable check reopens the saved plan and still exercises the archive drawers. Desktop and narrow views were inspected. See [the reproducible model-turn check](e2e/model-turn.test.mjs).

For the native UI check, set `XATP_TEST_RECORDING` to a private output directory to record the isolated rehearsal. The native test supplies an inert model endpoint and an isolated DSH home. Use [the final gate](e2e/README.md) to distinguish environment readiness from a qualified production run.
